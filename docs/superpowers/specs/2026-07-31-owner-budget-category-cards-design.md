# #1069 屋主預算與分類卡片設計規格

## 目標

預算頁用來規劃工程預估成本；帳本用來記錄實際資金流。畫面必須明確區分屋主設定的支出上限、預算項目加總，以及已經實際付款的金額。

## 核心金額

- **屋主預算**：每個工程案獨立保存的手動金額，可在預算頁摘要旁直接編輯。
- **目前工程預算**：所有預算項目的 `數量 × 單價` 加總，只能由項目內容自動計算。
- **已支出**：帳本中狀態為已付款的支出加總，不含待付款與作廢紀錄。
- **可用餘額**：`屋主預算 − 已支出`。
- **預估差額**：`屋主預算 − 目前工程預算`，顯示在目前工程預算旁；負值時提示預估已超出屋主預算。

帳本摘要中的「預算」改名為「屋主預算」，只讀取同一個屋主預算欄位。新增或刪除預算項目不會自動改變屋主預算。

## 預算頁版面

### 摘要列

依序顯示：

1. 屋主預算，旁邊提供小型編輯按鈕。
2. 目前工程預算，次要文字顯示預估差額。
3. 已支出。
4. 可用餘額。
5. 最右側 `＋` 新增選單。

所有金額維持無 `$` 的純數字格式。手機版只允許摘要區內部水平滑動，不造成整頁水平溢出。

### 分類卡片

- 移除空間篩選列及「空間／全部／未分空間」文字。
- 預算項目直接依帳本分類分組成卡片，例如材料、施工、工具、餐費。
- 每張卡片標題顯示分類名稱、項目數、目前工程預算小計與該分類實際支出。
- 沒有分類的舊項目集中在「待分類」卡片，不隱藏也不刪除。
- 沒有任何項目的分類仍顯示空卡片，方便直接新增第一筆項目。

### 快速增減項目

- 每張分類卡片右上角提供 `＋ 項目`，新增時自動帶入該分類。
- 項目列顯示名稱、數量、單價與小計；點擊列可開啟完整編輯表單。
- 項目列右側提供減號刪除；刪除後顯示短暫「復原」提示，避免每次跳出確認視窗。
- 全域 `＋` 保留「新增項目」與「管理分類」，移除「增加空間」。
- 新增項目不再詢問空間，內部自動使用工程案的預設空間。

## 資料與 API

- `projects` 新增 `owner_budget`，預設為 `0`，必須是安全的非負整數。
- Project、ProjectSummary 與 Dashboard API 都回傳 `ownerBudget`。
- 專案更新新增專用的屋主預算操作，不與工程名稱或狀態表單混在一起。
- `BudgetSpace` 與既有 `budget_spaces` 資料表暫時保留，但不顯示於預算頁。
- 新項目一律寫入該工程排序最前的預設空間；既有項目不因本次改版搬移或刪除。
- 工程清單中的預算摘要與「目前工程預算」仍使用預算項目加總；帳本摘要改用 `ownerBudget`。

## 清理現有預算

不透過全域資料遷移刪除任何預算，避免誤傷其他工程案。

提供專案範圍的「清空目前工程預算」操作：

- 只刪除該工程案的 `budget_line_items`。
- 保留屋主預算、分類、空間資料、帳本收入／支出／轉移及憑證。
- 操作必須明確顯示影響範圍並二次確認。
- 第一版不自動替使用者執行正式站清除；需在已登入的指定工程案中觸發。

## 錯誤處理與可及性

- 屋主預算超出安全範圍時阻止儲存並顯示清楚錯誤。
- 刪除失敗時保留原項目並顯示原因；只有後端刪除成功後才從畫面移除。
- 新增、編輯、刪除與復原皆可使用鍵盤操作，焦點不落入已關閉或隱藏的元素。
- 卡片標題、按鈕與金額狀態提供完整 `aria-label`，不能只依顏色表達超支。
