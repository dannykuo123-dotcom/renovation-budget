# #1069 帳本極致壓縮與左右模式設計規格

## 目標

在不變更 API、資料庫、帳務計算或既有資料的前提下，進一步壓縮工程帳本垂直空間，修正正式站品牌圖片路徑，並加入可切換的收入／支出左右模式。

## 已確認的視覺方向

### 品牌列

- 將目前分離的圖標與 HTML 文字改為一個完整外部 SVG 品牌鎖定圖。
- SVG 同時包含漸層動畫圖標、中文「彩虹室內設計」與英文 `RAINBOW INTERIOR DESIGN`。
- 中文採幾何黑體風格，英文採寬字距幾何無襯線風格。
- 動畫僅使用緩慢的漸層位移與光澤移動，避免閃爍；`prefers-reduced-motion` 時停止動畫。
- 圖片 URL 必須使用 Vite 的 `BASE_URL`，確保 GitHub Pages 的 `/renovation-budget/` 子路徑可正常載入。
- 桌機顯示完整品牌；窄螢幕以裁切容器只保留 SVG 左側圖標，避免擠壓導覽。

### 頁首空間

- 工程帳本頁完全移除「工程帳本」大標題區。
- 其他工程頁仍保留各自標題，不改變既有資訊架構。
- 帳本內容直接從摘要工具列開始。

### 摘要與新增

- 預算、收入、支出、餘額與 `＋` 合併成同一排。
- 四個數字使用更大的字級、等寬數字與更多水平留白。
- `＋` 位於最右側，維持深綠方形主操作；點擊後仍顯示支出、收入、轉移。
- 桌機為五段式工具列；手機在摘要容器內橫向滑動，不造成整頁水平捲動。
- 摘要數值不受任何篩選或顯示模式影響。

### 單列篩選

- 人員、類型、分類合併為同一條橫向篩選列。
- 人員只顯示圓形首字頭像，不顯示完整姓名。
- 完整姓名保留在 `title`、tooltip 與 `aria-label`。
- 類型與分類維持文字按鈕；選取狀態使用深綠底與白字。
- 選項超出寬度時，只允許篩選列內橫向滑動。

## 清單顯示模式

### 清單模式

- 維持目前依日期排序的四欄清單：人員、日期、項目、金額。
- 收入、支出與轉移混合顯示。
- 保留單筆風琴展開、hover、搜尋、排序、編輯與刪除。

### 左右模式

- 桌機分成兩欄：
  - 左欄「收入」
  - 右欄「支出」
- 每欄顯示該類型的交易，並各自沿用目前日期排序。
- 收入與支出列保留人員頭像、日期、項目、金額及風琴明細。
- 轉移不屬於工程收入或支出，放在兩欄下方的全寬「轉移」區。
- 沒有內容的區域使用短空狀態，不加入說明段落。

### 手機左右模式

- 收入與支出改為同區塊內的兩個頁籤，不強行並排兩欄。
- 預設開啟收入；使用者切換後保持在同一頁籤，直到離開帳本。
- 全寬轉移區固定放在頁籤內容下方。

### 模式切換

- 清單工具列右上角提供清單／左右模式圖示按鈕。
- 按鈕使用 Phosphor 圖示、`aria-label`、`aria-pressed` 與 tooltip。
- 模式選擇以專案為範圍保存於現有篩選快取，不寫入後端。
- 搜尋、人員、類型、分類與日期排序在兩種模式間共用。
- 切換模式不重設篩選或展開紀錄；同一時間仍只展開一筆。

## 資料與邏輯

- 既有 `CashbookActivity` 為唯一顯示資料來源。
- 新增純顯示輔助函式，將活動分成 `income`、`expense`、`transfer` 三組。
- 分組發生在既有搜尋、人物、類型、分類與排序完成後。
- 轉移仍不計入工程收入、支出或餘額。
- 待處理與作廢規則、分類只作用於支出、雙方皆可查到轉移等既有邏輯不變。

## 響應式與無障礙

- 320px 不產生應用程式層級的水平捲動。
- 摘要與篩選可在自己的容器內橫向滑動，並保留觸控慣性。
- 所有只有圖示或首字的控制都有完整可存取名稱。
- 模式切換與頁籤可使用鍵盤操作並有清楚的 focus 樣式。
- 尊重 `prefers-reduced-motion`。
